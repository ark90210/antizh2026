# Операция Антижопич 2026

Личное веб-приложение: программа тренировок, питание и трекер прогресса.
Работает офлайн после первой загрузки, данные трекера хранятся в
`localStorage` браузера на устройстве.

## Структура проекта

```
antizh2026/
├── index.html              — разметка всех 4 экранов (табов)
├── css/
│   └── style.css            — все стили (дизайн-токены в :root)
├── data/
│   ├── training.js          — упражнения по дням (редактируйте здесь)
│   └── nutrition.js         — приёмы пищи и БЖУ
├── js/
│   ├── ui.js                 — рендер тренировок/питания из data/*
│   ├── tracker.js            — логика трекера: localStorage, расчёты, график
│   └── app.js                 — инициализация, навигация по табам
└── README.md
```

## Как опубликовать через GitHub Pages

1. Создайте новый репозиторий на GitHub (например `antizh2026`).
2. Залейте туда все файлы из этой папки, сохранив структуру:
   ```bash
   cd antizh2026
   git init
   git add .
   git commit -m "Первая версия приложения"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/antizh2026.git
   git push -u origin main
   ```
3. В репозитории на GitHub: **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите `Deploy from a branch`.
5. Branch: `main`, папка `/ (root)` → **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_АККАУНТ.github.io/antizh2026/`
7. Откройте этот адрес на телефоне и добавьте на главный экран
   (в Safari/Chrome: "Поделиться" → "На экран Домой") — будет
   открываться как обычное приложение.

## Важно про сохранение данных

Трекер хранит данные в `localStorage` — **это память конкретного
браузера на конкретном устройстве**. Из этого следует:

- Если открыть сайт в другом браузере или на другом телефоне —
  данных там не будет (нужно вводить заново или переносить через CSV).
- Очистка кэша/данных сайта в браузере сотрёт записи трекера.
- Режим инкогнито не сохраняет данные между сессиями.
- **Рекомендация**: раз в несколько недель нажимайте кнопку
  **"CSV"** в разделе "Прогресс" — она скачает файл с резервной
  копией всех записей. Если нужно восстановить данные на новом
  устройстве, можно вручную ввести записи заново, ориентируясь
  на CSV.

## Как редактировать программу тренировок

Откройте `data/training.js`. Каждый день — это объект в массиве
`TRAINING_DAYS` с полями `name`, `focus`, `exercises` (массив
упражнений с `sets`, `weight`, `tip`, `alt`). Измените текст —
изменения появятся на сайте сразу после обновления файла в
репозитории (GitHub Pages пересоберёт сайт автоматически за
1–2 минуты после `git push`).

## Как редактировать питание

Откройте `data/nutrition.js`, массив `MEAL_PLAN`. Структура та же
логика: время приёма, название, описание, массив макросов для
отображения как чипсы.

## Как изменить константы расчётов в трекере

Откройте `js/tracker.js`, секция в начале файла:

```js
const START_WEIGHT = 95;          // стартовый вес, кг
const GOAL_WEIGHT = 80;           // целевой вес, кг
const KCAL_PER_1000_STEPS = 60;   // ккал на 1000 шагов
const KCAL_PER_WORKOUT = 250;     // ккал за тренировку
```

Поменяйте значения под себя, если параметры тела или нормативы
расхода калорий изменятся (например, после прохождения фазы 1).

## Технологии

- Чистый HTML/CSS/JS, без сборщиков и фреймворков
- [Chart.js](https://www.chartjs.org/) — график веса (через CDN)
- [Tabler Icons](https://tabler.io/icons) — иконки (через CDN)
- Шрифты Oswald + Inter + JetBrains Mono (Google Fonts, через CDN)

Для работы нужен только статический хостинг — GitHub Pages
подходит идеально, дополнительный backend не требуется.
